 🧮 Calculadora Simples

Projeto desenvolvido como parte de atividade acadêmica para praticar e fixar os conceitos fundamentais do **Git** e **GitHub** em um trabalho colaborativo em grupo.

📌 Sobre o Projeto

O objetivo principal deste repositório não é apenas a criação da calculadora em si, mas sim a vivência prática do fluxo de trabalho com Git em equipe:
- Criação e gerenciamento de branches (ramificações).
- Resolução de conflitos de merge.
- Prática de Pull Requests (PRs) e revisão de código (Code Review).
- Padronização de mensagens de commit.

A aplicação é uma calculadora simples que realiza as 4 operações matemáticas básicas: Soma, Subtração, Multiplicação e Divisão.

🚀 Funcionalidades

- Soma: Adição de dois números.
- Subtração: Diferença entre dois números.
- Multiplicação: Produto de dois números.
- Divisão: Coeficiente com tratamento de divisão por zero.
- Menu Interativo: Navegação simples pelo terminal.

 🛠️ Tecnologias Utilizadas

- Linguagem de Programação (ex: Python, C, Java, JavaScript)
- Git & GitHub (Controle de Versão)


 ⚙️ Como Executar o Projeto

1. Clonar o repositório:
   git clone https://github.com/seu-usuario/calculadora-git.git

2. Acessar a pasta do projeto:
   cd calculadora-git

3. Executar o código principal:
   python main.py
